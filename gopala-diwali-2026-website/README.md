# Gopala Diwali 2026 Website — updated from the 45-page final catalogue

## Files
- `index.html`, `styles.css`, `app.js`: responsive static website.
- `assets/products.json`: curated product cards and exact PDF page references.
- `assets/pages/page-01.jpg` through `page-45.jpg`: preview images rendered from the uploaded 45-page catalogue.
- `assets/Gopala_Diwali_2026_Catalogue.pdf`: the correct 45-page catalogue supplied for this update.

## Preview locally
Open `index.html` in a browser or use a local static server.

## Host on Vercel
Import the GitHub repository, select the directory containing these files as Root Directory, use Framework Preset `Other`, leave Build Command blank, and set Output Directory to `.`.

## Important
Product card details are selected from the supplied catalogue. The complete PDF remains the final source for all products and packaging details. Review prices and descriptive text before publishing commercially.
