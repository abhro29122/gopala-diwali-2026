# Gopala Diwali 2026 Website

A responsive static website built from the final `Gopala_Diwali_2026_Catalogue.pdf`.

## Preview locally
- Unzip this folder.
- Open `index.html` in a browser. For the best experience, serve it as a static site (see below).

## Host on Vercel
1. Extract this ZIP.
2. Create a new GitHub repository and upload the contents of this folder (so `index.html`, `styles.css`, `app.js`, and `assets/` are at the repository root).
3. In Vercel, import that repository.
4. Framework preset: **Other**; Build command: leave blank; Output directory: `.`.
5. Deploy.

It is a static site and needs no build command, API key, or server-side environment variables.

## Features
- Responsive Diwali-themed landing page in Gopala maroon, cream, and gold.
- Product collection with category filters and search by product name/code.
- Product detail modal with catalogue page and WhatsApp enquiry link.
- Full 42-page catalogue PDF view/download.
- Product and page imagery rendered from the supplied PDF.

## Notes
The catalogue PDF remains the source of truth. The cards show selected catalogue items and their catalogue page imagery; the full PDF is linked for complete details. Prices and descriptions shown in cards were transcribed from visible catalogue pages and should be reviewed before publishing commercially.
