GOPALA DIWALI 2026 WEBSITE REPLACEMENT PACKAGE

This package contains:
- index.html: responsive burgundy-and-gold catalogue website
- catalogue-data.json: product details and updated corrections
- pages/page-01.jpg through pages/page-42.jpg: page images extracted from
  Gopala_Diwali_2026_Updated_Catalogue_Revised(4).pdf

Preview locally: open index.html in a browser.
To publish on Vercel/GitHub: replace the contents of the existing
Gopala_Diwali_2026_Web_Catalogue folder with this folder's contents and push
to the connected production branch. The original Gopala logo image was not
available in the provided image ZIP, so a text wordmark is used in this
replacement package; add gopala-logo.png and change the wordmark to an img
if you want to restore the exact original logo asset.
